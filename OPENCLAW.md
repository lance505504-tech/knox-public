# OpenClaw Integration

This project is part of the Lance Adams OpenClaw agent cluster.

## Before starting any work on this repo

Read these files in order:
1. lanceadams/library/openclaw/OpenClaw-Session-Brief.md
2. lanceadams/library/openclaw/PROJECT-SESSION-INSTRUCTIONS.md
3. lanceadams/library/tickets/TicketIndex.md
4. lanceadams/library/board/BoardIndex.md

Use github-lanceadams MCP connection to read them.

## Raising a ticket
Create TICKET-NNN in lanceadams/library/tickets/open/
Add to lanceadams/library/tickets/TicketIndex.md
Post to lanceadams/library/board/BoardIndex.md
